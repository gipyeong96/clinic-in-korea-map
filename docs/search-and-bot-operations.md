# 영문 기평헬스 맵 검색 유입과 봇 운영

- 해외환자가 병원을 찾고 전화·길찾기까지 이어지도록 돕는다. SEO·GEO·AEO 성과는 검색 클릭, AI 추천 유입, 전화·길찾기 클릭으로 확인한다. 전체 운영비 목표는 월 3만원 이하로 관리한다.
- 검증된 Googlebot·Bingbot과 AI 검색·인용용 OAI-SearchBot의 접근을 유지한다. AI 학습용 GPTBot은 검색용 OAI-SearchBot과 별도로 취급한다.
- 대량 학습·백링크 수집 봇은 Vercel 요청량, 경로, 전송량을 확인한 뒤 확인된 봇만 선별 차단한다. Amazonbot·SE Ranking 백링크 봇처럼 이미 적용한 규칙은 추가 전에 현황을 확인한다.
- 정체가 불분명한 자동화는 병원 목록·상세의 반복 패턴을 확인하고 해당 요청에만 제한을 검토한다. 국가나 브라우저 이름만으로 일괄 차단하지 않는다.
- 변경 전후 같은 길이의 기간과 요일을 비교한다. Vercel에서는 봇별 요청·차단, 전송량, 페이지 재생성 사용량을 보고, Search Console과 GA4에서는 자연검색 클릭과 환자 행동을 확인한다. 정상 접근이나 검색 노출에 영향이 발견되면 해당 규칙을 되돌린다.
- GA4의 `/measure/*`는 실제 URL 대신 보내는 화면 유형이다. 병원명·ID·지역명·진료과·검색어·쿼리 문자열을 GA4로 보내지 않는다. Vercel에는 실제 요청 경로가 기록된다. 시간대와 집계 단위를 맞춰 비교하고 GA4 세션과 CDN 요청을 같은 수치로 해석하지 않는다.
